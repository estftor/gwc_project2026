## About the Game

**Park & Panic** is a college-themed game where players must navigate a parking garage, overcome obstacles, and find a parking spot before time runs out.

Each level represents a different floor of a parking garage. Along the way, players encounter obstacles that trigger mini-games. Winning a mini-game allows the player to continue, while losing lowers their grade. Players start with an A, but every failed obstacle costs them a letter grade. Losing three mini-games means failing and restarting the game.

The goal is simple: park your car, beat the clock, and make it to class before your GPA takes a hit!

## Features

- **Pixel-Art Graphics:** A 2D top-down game with a pixel-art visual style.
- **Parking Garage Levels:** Explore three planned levels, each representing a different garage floor.
- **Mini-Games:** Complete challenges triggered by obstacles throughout the garage.
- **Grade System:** Start with an A and lose a letter grade when you fail an obstacle.
- **Countdown Timer:** Race against the clock to find a parking spot before class starts.
- **Win and Lose Conditions:** Complete the level before time runs out, or face the consequences of being late.
- **Replayability:** Restart and try again when things go wrong.

## How to Play

1. Start the game and navigate your car through the parking garage.
2. Avoid obstacles and reach mini-game challenges.
3. Complete each mini-game successfully to continue.
4. Be careful! Failing an obstacle lowers your grade.
5. Avoid losing three mini-games, or you will have to restart.
6. Find a parking spot before the timer reaches zero.

**Can you park in time and make it to class with your A intact?**

## Running the Game

1. Install [Godot Engine](https://godotengine.org/).
2. Clone or download this repository.
3. Open Godot and select **Import**.
4. Navigate to the downloaded project folder and select `project.godot`.
5. Open the project and press **F6** to run the current scene, or **F6/F5** as appropriate for your setup. Press **F5** to run the project's main scene once it is configured.
